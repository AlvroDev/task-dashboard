# Task Dashboard

Dashboard de gestión de tareas desarrollado como challenge frontend.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui
- TanStack Query
- Axios

## Instalación

```bash
git clone https://github.com/Alvro0o/task-dashboard.git
cd task-dashboard
pnpm install
pnpm dev
```

## Funcionalidades

- Listar tareas con paginación
- Crear tarea con validación de formulario
- Editar tarea
- Eliminar tarea con confirmación
- Filtros por estado y usuario
- Búsqueda por título y descripción

## Limitaciones conocidas

DummyJSON es una API de prueba que no persiste cambios reales.
Las operaciones de crear, editar y eliminar funcionan correctamente
a nivel de código pero los cambios no se guardan en el servidor.
